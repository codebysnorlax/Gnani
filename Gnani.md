# Gnani.ai Documentation

> Documentation for the Gnani.ai developer platform: Speech APIs, Agent Builder, and the Agent Builder Platform API.

Gnani.ai builds voice AI for Indian languages. This documentation has three sections. Choose the one that matches what you want to build.

> [card] [Gnani AI APIs](https://docs.gnani.ai/api/introduction/introduction.md)
>
> Add speech-to-text, text-to-speech and voice cloning to your own application over REST, streaming and batch APIs.

> [card] [Gnani AI Agents](https://docs.gnani.ai/introduction.md)
>
> Build, configure, test and deploy voice agents in the Agent Builder console, with knowledge bases, integrations and analytics.

> [card] [Gnani AI Agent Builder APIs](https://docs.gnani.ai/Platform/platform-introduction.md)
>
> Create and manage agents, FAQs, conversations and the chat widget from your own code over REST.

Not sure which one you need? Use the Speech APIs when you are building your own voice pipeline. Use Agent Builder when you want Gnani to run the conversation. Use the Agent Builder Platform API to manage those agents from code.
